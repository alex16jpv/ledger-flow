# Categories

User-scoped categories for transactions and budgets. W-16 ships the category picker: a searchable
sheet filtered by the movement type, a "Recent" strip with the three categories used most often in
the last 90 days (from `GET /stats/spending?groupBy=category`), and an inline "New category" form so
the user never leaves the transaction they were writing. The grid, archive/restore and the full form
arrive with W-25.

# Decision log

Every decision that shaped the UI, newest first. This is the one file in the specification that keeps
the tracker's codes (`F-nn`, `P-nn`, `W-nn`, `D-nn`): it is the audit trail, and it is what ties a
screen back to the row that asked for it in `PROGRESO.md`. The screens themselves are named after what
they are, never after a ticket.

| 2026-09-11 | **P-46 · the install card insists by platform, and says only what is true there** (owner's decision). It never appears on a **desktop**: the browser puts its own install button in the address bar and Settings › About carries the row, so a card on top of that is insistence without a reason. On **Android** it keeps the seven-day snooze and gives up on the third dismissal. On **iOS** it snoozes three days and **never gives up**, because Safari is the only place that really deletes the data and the only one where no install prompt of any kind exists — a page cannot ask, the way it can ask for a location.
